# SOLE ARCHIVE

NIKE/JORDAN、SALOMON、On、HOKAのスニーカーを眺める独立系ギャラリーです。ブランド別の画面演出、展示モード、お気に入り機能を備えています。

## ローカル確認

ビルドは不要です。`dist` を静的ファイルとして配信してください。

```sh
python3 -m http.server 8080 --directory dist
```

ブラウザで `http://localhost:8080` を開きます。お気に入りはブラウザ内に保存されます。

## デプロイ

Vercelの出力ディレクトリは `dist` です。`main` ブランチを本番ブランチに設定して運用します。

写真の出典はサイト内の「写真・掲載について」と `dist/assets/credits.json` に記載しています。商品名・商標・写真の権利は各権利者に帰属します。

## 写真のライセンス

掲載写真はすべて、再利用条件が明示された Wikimedia Commons の写真です（ブランド公式の商品画像は使っていません）。

- AIR JORDAN 1：Smithsonian Institution / CC0 1.0
- それ以外の7点：各撮影者 / CC BY-SA 4.0

CC BY-SA の写真は、長辺1500pxへの縮小と WebP 変換のみ行い、トリミング等の加工はしていません。撮影者名とライセンスは `credits.json` とサイト内に表示しています。

当初は各ブランド公式サイトの商品画像を使っていましたが、出典表示だけでは利用許諾にならないため、2026-10-08 に差し替えました。公式画像と同じモデルの自由ライセンス写真が見つからなかったため、掲載モデルも一部変更しています（例：Bondi 9 → Bondi 8）。
