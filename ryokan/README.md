# 湯宿 月待荘 — 旅館サイトの制作見本

架空の温泉旅館「月待荘（つきまちそう）」のホームページ一式です。
奥飛騨・平湯の山あいにある全十二室の宿、という設定で組み立てています。

```
ryokan/
├── index.html              # サイト本体（HTML / CSS / JS を一枚に収めています）
├── images/                 # 生成した SVG 素材（14点）
└── tools/
    └── generate_images.py  # images/ を作り直すスクリプト
```

ブラウザで `index.html` を開けばそのまま動きます。ビルドは要りません。

## 画像について

写真素材は使わず、浮世絵・水墨画の意匠をベクタのレイヤとして組み立てています。
稜線・霞・水面・湯気・灯りといった部品を関数にして、季節や時刻のパレットを
差し替えることで、全カットの空気感を揃えています。

作り直すときは、

```bash
python3 tools/generate_images.py
```

外部ライブラリは使っていません（標準ライブラリのみ）。

| ファイル | 中身 |
|---|---|
| `hero.svg` | 表紙。宵の口、月の下に灯る宿 |
| `approach.svg` | 夕暮れの門前。提灯の列と石畳 |
| `onsen-rotenburo.svg` / `onsen-kashikiri.svg` | 露天と檜の貸切風呂 |
| `room-tsukimi.svg` / `room-hanare.svg` / `room-kaze.svg` | 客室三室。間取りを変えてあります |
| `cuisine-dinner.svg` / `cuisine-breakfast.svg` | 会席と朝の膳（真上からの構図） |
| `season-{spring,summer,autumn,winter}.svg` | 四季 |
| `crest.svg` | 家紋ふうの印（favicon 兼用） |

## 女将「月子」（チャットボット）

右下から呼び出せる、素泊まりの問い合わせ窓口です。外部 API は使わず、
キーワードの一致文字数に intent ごとの重みを掛けて返答を選んでいます。

- 表記ゆれの吸収：全角→半角、カタカナ→ひらがな、記号・長音の除去
- 具体的な話題（貸切風呂・雪見・一人旅など）が総称的な話題（温泉・宿泊）に
  埋もれないよう、intent に重み `w` を持たせています
- 空室、料金、泉質、食事とアレルギー、道のり、チェックイン、キャンセル、
  子ども連れ、ペット、支払い、四季、記念日など 24 の話題に対応
- 長い返答は書き出しが読めるよう、末尾ではなく頭に合わせてスクロールします

返答を足すときは `INTENTS` に一件加えるだけです。

## 表記・文字まわり

本文は Shippori Mincho B1（Google Fonts）、欧文は Cormorant Garamond。
見出しと表紙は `writing-mode: vertical-rl` の縦書きです。

縦書きは、和文フォントが当たらない環境だと字送りが崩れることがあります
（欧文フォントと和文フォントが混ざると、縦書きの字幅が取れないため）。
`--serif` のフォールバックに Hiragino / Yu Mincho / Noto Serif JP を並べてあるのは
そのためです。
